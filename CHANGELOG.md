## [1.0.0] - 2026-10-16

### Added
- Initial public release of WDLE.
- 14-module structured learning roadmap from internet fundamentals through React.
- 20-chapter handbook covering every layer of web development.
- 11 projects across beginner, intermediate, and advanced levels, each with a 100-point rubric, viva questions, and extension ideas.
- Practice lab with 14 HTML, CSS, and JavaScript exercises plus 4 weekly mini-projects.
- 7 fully documented starter templates with complete source code and deployment instructions.
- Complete deployment handbook with 22 sections covering GitHub Pages, Vercel, Netlify, environment variables, custom domains, HTTPS, and troubleshooting.
- Git & GitHub guide with installation, branching, pull requests, conflict resolution, and team workflow.
- Resource hub with HTML, CSS, JavaScript, Git, tools, and external references.
- Assessment system with 9 multiple-choice quizzes (auto-scored with explanations), 4 practical assignments, and topic-wise viva questions.
- Faculty teaching guide with proposed 12-week schedule, learning outcomes, classroom demonstration ideas, lab activities, assessment strategy, and instructions for adding content.
- About WDLE page and Credits & References page.
- Custom 404 page.
- Global search across modules, chapters, projects, exercises, templates, resources, and quizzes.
- LocalStorage-backed progress tracking for lessons, modules, exercises, quiz scores, and bookmarks — no login required.
- Dark/light theme with system preference detection and toggle.
- Fully responsive design (mobile 360px, tablet 768px, desktop 1280px+).
- WCAG AA accessibility: semantic HTML5, keyboard navigation, visible focus indicators, ARIA labels.
- 8-document Markdown documentation suite: WEBSITE_HANDBOOK.md, LEARNING_ROADMAP.md, FACULTY_GUIDE.md, PRACTICE_WORKBOOK.md, DEPLOYMENT_HANDBOOK.md, GIT_GITHUB_GUIDE.md, CHEAT_SHEETS.md, QUICK_REFERENCE.md.
- Comprehensive README, CONTRIBUTING guide, and MIT LICENSE.
- Placeholder DSVV logo asset (clearly marked for replacement with the official emblem).
- Sample project source folder with starter code for the Personal Introduction Page project.

### Tech Stack
- React 18.3
- Vite 5.4
- React Router 6.28
- Lucide React 0.460
- Vanilla CSS3 with custom properties (no CSS framework)
- JavaScript ES6+ (no TypeScript)
- LocalStorage for progress tracking (no backend)

### Documentation
- README.md with complete setup, build, deployment, and contributing instructions.
- CONTRIBUTING.md with content contribution patterns for all data modules.
- 8 docs/ Markdown files totaling over 44,000 words of curated learning content.

## Release Notes

### v1.0.0

This is the inaugural release of WDLE, built by the Software Development Cell of the Department of Computer Science at Dev Sanskriti Vishwavidyalaya. The platform represents a student-led initiative to create a reusable, evolving learning ecosystem for current and future batches of Computer Science students.

The release includes:
- A complete, navigable React+Vite website with 14 distinct page types
- Over 150 pages of structured learning content
- 11 graded projects with evaluation rubrics
- 14 hands-on practice exercises
- 7 starter templates with complete source code
- 9 multiple-choice quizzes with automatic scoring and explanations
- 4 practical assignments and topic-wise viva questions
- A faculty teaching guide with a proposed 12-week schedule
- A complete deployment handbook
- A complete Git & GitHub guide
- A resource hub with curated external documentation links
- LocalStorage-backed progress tracking without login
- Dark/light mode with system preference detection
- Full responsive design (mobile, tablet, desktop)
- WCAG AA accessibility compliance
- 8 Markdown documentation files totaling 44,000+ words
- Comprehensive README and CONTRIBUTING guide
- MIT License

The platform is intended as an educational resource, not an officially launched institutional product of DSVV. The official DSVV website is https://www.dsvv.ac.in/.

Future versions will focus on translations, additional content, and possible backend integration for cross-device progress sync.
